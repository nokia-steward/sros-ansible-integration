# Community Guide

`nokia.sros` is an open-source project led by Nokia and maintained together with community contributors. There is no commercial support and no SLA; help comes from the documentation, issues and the maintainers.

## Ways to contribute

- **Bug reports** — [GitHub Issues](https://github.com/nokia-steward/sros-ansible-integration/issues) with reproduction, Ansible and SR OS versions, and task output (no passwords).
- **Features** — Open an issue describing the use case before large changes.
- **Pull requests** — See the [Developer Guide](developer-guide.md) and [CONTRIBUTING](https://github.com/nokia-steward/sros-ansible-integration/blob/master/CONTRIBUTING.md) on GitHub.
- **Documentation** — Fix typos or clarify guides under `docs/`; run `make docs` after docstring changes.

## Code of conduct

Follow the [Ansible Community Guidelines](https://docs.ansible.com/ansible/devel/community/code_of_conduct.html) and treat other contributors respectfully.

## Releases

Tagged releases are published to [Ansible Galaxy](https://galaxy.ansible.com/ui/repo/published/nokia/sros/) and attached to [GitHub releases](https://github.com/nokia-steward/sros-ansible-integration/releases). The documentation site matches the version in `galaxy.yml`.

Thank you for improving SR OS automation for the community.
