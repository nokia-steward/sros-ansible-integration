# nokia.sros.md cliconf plugin

**Cliconf plugin to configure and run CLI commands on Nokia SR OS devices (model-driven mode)**

Use with `ansible_network_os: nokia.sros.md`.

## Synopsis

* This plugin provides low level abstraction APIs for sending CLI commands and receiving responses from Nokia SR OS network devices.
